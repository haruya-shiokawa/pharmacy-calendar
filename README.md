# 患者予定カレンダー

薬局チーム向けの患者予定管理カレンダーアプリケーションです。

## 機能

### ✅ 実装済み機能

1. **サーバー保存対応**
   - 複数人で共有できるサーバーストレージ
   - サーバーが利用できない場合は自動的にローカルストレージにフォールバック

2. **名前の重複チェック**
   - 同じ日に同じ患者名を登録しようとすると警告を表示
   - 確認後に重複登録も可能

3. **印刷用レイアウト**
   - 印刷ボタンをクリックするだけで最適化されたレイアウトで印刷
   - A4横向きに最適化

4. **CSV出力**
   - 現在表示中の月のデータをCSV形式でエクスポート
   - Excel対応（UTF-8 BOM付き）

5. **自動反映機能**
   - 患者名と次回来局日数を入力すると、該当日に自動的に患者名を登録

## セットアップ

### 1. 依存関係のインストール

```bash
cd pharmacy-calendar
npm install
```

### 2. アプリケーションの起動

#### サーバーとクライアントを同時に起動（推奨）

```bash
npm start
```

これにより以下が起動します：
- サーバー: http://localhost:3001
- クライアント: http://localhost:5173

#### 個別に起動する場合

```bash
# ターミナル1: サーバー起動
npm run server

# ターミナル2: クライアント起動
npm run dev
```

## 使い方

### 基本操作

1. **患者名の入力**: 各日付の「患者名」欄に患者名を入力
2. **次回来局日数の入力**: 「日数」欄に次回来局までの日数を入力
3. **自動反映**: 日数を入力すると、該当日に自動的に患者名が登録されます

### CSV出力

1. 画面右上の「📊 CSV出力」ボタンをクリック
2. 現在表示中の月のデータがCSVファイルとしてダウンロードされます
3. Excelで開くことができます

### 印刷

1. 画面右上の「🖨️ 印刷」ボタンをクリック
2. 印刷プレビューが表示されます
3. A4横向きで最適化されたレイアウトで印刷できます

### ストレージの切り替え

- サーバーが起動している場合: 🌐 サーバー保存（複数人で共有可能）
- サーバーが起動していない場合: 💾 ローカル保存（個人のブラウザに保存）

## データの保存場所

- **サーバーストレージ**: `pharmacy-calendar/data/calendar-data.json`
- **ローカルストレージ**: ブラウザのlocalStorage（キー: `pharmacy-calendar-data`）

## トラブルシューティング

### サーバーに接続できない

- サーバーが起動しているか確認してください（`npm run server`）
- ポート3001が使用可能か確認してください
- 自動的にローカルストレージにフォールバックします

### データが保存されない

- ブラウザのlocalStorageが有効か確認してください
- サーバーモードの場合、`data/` ディレクトリへの書き込み権限を確認してください
